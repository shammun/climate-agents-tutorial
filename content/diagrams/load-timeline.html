📂 What Gets Loaded When

Context is added in stages — only what's needed, when it's needed

🟡
Lightweight — only summaries, not full skill text
1. Session starts
  • CLAUDE.md / AGENTS.md loaded (full text)
  • name + description of every defined agent
  • name + description of every skill
  • ⚡ Keeps startup fast — summaries only
🔵
Each agent has its own isolated context — no memory of siblings
2. Task delegated to an agent
  • agent gets a fresh, empty context
  • agent body (AGENTS.md entry) + project rules
  • skills listed in skills: are preloaded
  • 🧩 Fully isolated — siblings can't interfere
🟣
Skills are lazy-loaded — only pay the token cost when used
3. A skill is invoked
  • full SKILL.md text loads at that moment
  • helper scripts run on demand
  • keeps context lean until actually needed
  • 💰 Saves tokens — no cost until needed
🟠
This isolation is what makes agents composable and reusable
4. Agent finishes
  • only the final answer returns
  • intermediate steps stay inside the agent
  • caller never sees the working context
  • 🔒 Private by default — clean outputs
🌟 Did you know? A skill's full text might be 2,000 tokens — by lazy-loading, an agent that never needs it saves those tokens entirely!
